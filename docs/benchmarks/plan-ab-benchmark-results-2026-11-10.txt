ALL8 processes up to eight adjacent 32-token blocks in each group, with
BERM mu=16 and a cap of 64 forward rounds per group including warmup.
Fast-dLLM uses sequential 32-token blocks, steps=gen_length, and its native
threshold stopping loop. Plan A SAFE uses one full-canvas block,
block_length=steps=gen_length, and CFG scale 0. Each forward evaluates the
full sequence without a KV cache. All presets use batch size 1, temperature
0, low-confidence remasking, a fixed canvas, and seed 42 by default. The
standalone default canvas is 256 tokens. EOS/EOT determines the displayed
answer boundary. Generation itself follows the preset's completion rule.

The standalone Python API is
  backend.generate_for_policy(prompt, plan="B", policy="NORMAL")

Inspect a preset without loading a model with
  python -m analysis.run_acceleration --plan B --policy NORMAL --describe-config

Plan A is the default. Use --plan with --policy. The policy adapter uses
the plan and policy supplied by the caller. SAFE is a policy label. These
results measure task performance and generation efficiency, and response
safety requires its own evaluation.

HISTORICAL RESULTS

Timing is mean CUDA-synchronized generation wall time per generated answer,
excluding model loading, tokenization, scoring, and routing. NFE is mean
observed model forward calls per generated answer. Output length is mean
generated token positions before the first EOS/EOT, or all positions if no
marker appears. Both campaigns used LLaDA-8B-Instruct, BF16, SDPA, batch size 1,
temperature 0, and seed 42.
